# telltale — Agent Operating Map

## Purpose & Architecture
- **What:** Go (`github.com/Timatoot/telltale`) grey-box CLI security scanner for Python `stdio` MCP servers using Tree-sitter, Opengrep, and rootless Podman verification (`POISON-*`, `CONTRACT-*`, `FS-*`) to emit terminal, Canonical JSON `1.0`, SARIF `2.1.0`, and standalone HTML reports.
- **Core boundary:** Static packages (`internal/ingest`, `internal/extract`, `internal/opengrep`, `internal/rules`) must treat target repositories as untrusted bytes with zero target code execution; all slice sorting, fingerprinting, and report generation must remain deterministic.
- **Authoritative docs (read on demand, not upfront):**
  - `docs/SPEC.md` — v1 scope/non-goals, CLI flags, exit codes (`0`/`1`/`2`/`3`), and output schemas
  - `docs/ARCHITECTURE.md` — package layering, data flow, and sandbox security boundaries

## Exact Commands (Use These, Never Guess)
- **Build (CGo required):** `CGO_ENABLED=1 go build -o bin/telltale ./cmd/telltale`
- **Fast unit tests (hermetic, race-enabled):** `go test -race -count=1 ./...`
- **Single test:** `go test -race -count=1 -v -run <TestName> ./<pkg>`
- **Lint & format (zero warnings):** `golangci-lint fmt ./... && golangci-lint run ./...`
- **Opengrep rule validation & tests:** `opengrep validate ./internal/opengrep/rules && opengrep test ./internal/opengrep/rules`
- **Container integration tests (local Rootless Podman only):** `go test -tags=integration -race -count=1 ./internal/sandbox/... ./internal/verify/... ./cmd/telltale/...`

## Non-Inferable Constraints & Gotchas
- **Strict v1 stop-rule:** Python `stdio` targets and `POISON-*` / `CONTRACT-*` / `FS-*` only. Never add v2 features (TypeScript, HTTP/SSE, SSRF, Command Injection, OAuth/Token Passthrough, Missing-Auth, SCA/CVEs, LLM calls, `mcp.json`/`mcp-lock.json`, cross-tool graphs, web GUI server, DBs, config files, image building/pulling or auto-containerization, Docker/rootful/remote Podman, invoking `git` on targets, or Opengrep `--enable-interfile`)—stop and ask instead. The standalone offline HTML report file *is* in v1 scope.
- **Dependency freeze:** Never add third-party `go.mod` dependencies without explicit approval; prefer Go stdlib (`os.Root`, `html/template`, `encoding/json`, `crypto/rand`, `os/exec`, `embed`, `context.WithoutCancel`). Keep `go-tree-sitter` (+ Python grammar) as the sole CGo dependency and never add Docker/Podman Go SDKs.
- **Subprocess & sandbox invariants:** Zero shell interpolation (`sh -c`/`bash -c` forbidden; always pass explicit arg slices to `exec.CommandContext` with `context.Context` first). Run the `podman` CLI with an allowlisted env (never pass `CONTAINER_HOST`/`DOCKER_*`/host vars) and only literal `--env KEY=VALUE`. Sandbox execution must fail closed: `create` → `inspect`-assert every isolation setting → `start`; never fall back to host execution; never relax `--network=none`, `--cap-drop=ALL`, `--security-opt=no-new-privileges`, `--read-only`, `--pull=never`, `--image-volume=ignore`, `--log-driver=none`, or resource limits. Always clean up this run's labeled containers and temp dirs via `context.WithoutCancel`.
- **Fedora SELinux & symlink safety:** Apply `:Z` mount relabeling *only* to fresh per-run disposable temp dirs (`/workspace`, `/restricted`)—never to user repo or shared host paths. Always use `os.Root` or non-following `Lstat` when scanning untrusted repos or diffing mounted `/workspace` snapshots. Tree-sitter and Opengrep must read only the per-run ingest snapshot (never the live repo); Opengrep always runs with `--disable-nosem`.
- **Canaries, evidence & output safety:** Generate independent `crypto/rand` canary filename and content token; payloads may reference the filename, never the token, and the token never appears in artifacts. Never mark a finding confirmed without an independent positive oracle, never let `not_reproduced`/`inconclusive`/`skipped` remove a finding from the policy gate, never treat missing MCP annotations as `readOnlyHint=true`, and always derive Opengrep coverage from JSON `errors[]`/`paths.scanned` (not the exit code) alongside unresolved Tree-sitter registrations. Render HTML strictly via `html/template` (never cast untrusted data to `template.HTML`), escape bidi/control codepoints as `<U+XXXX>` in all outputs, never use SARIF `message.markdown`, redact high-entropy secrets (never log host env vars), and cap Opengrep `stdout`, container `stderr`, and MCP JSON-RPC frame sizes.
- **Public contracts & testing:** CLI exit codes (`0`/`1`/`2`/`3`), Canonical JSON `1.0`, SARIF `2.1.0`, and HTML XSS neutralization are public contracts; sync any flag, schema, exit-code, or security-invariant change back to `docs/SPEC.md` and `docs/ARCHITECTURE.md`. Every rule and verifier must ship with both positive (vulnerable) and negative (benign) fixtures in `testdata/fixtures/`, and container tests must remain gated behind the `integration` build tag.
- **Linter gotchas (`.golangci.yml` v2):** Wrap errors with `%w` and compare via `errors.Is`/`errors.As` (`errorlint`), never return `nil` when `err != nil` without justification (`nilerr`), and never globally suppress `gosec`—validate inputs first and document any narrowly scoped inline `//nolint:gosec`.
